I'm a **DevOps Engineer** with 7+ years across AWS, Kubernetes, and CI/CD — currently delivering 99.9% uptime on production banking platforms under PCI-DSS, SOC 2, and OSFI compliance. The core of my work is DevOps: building, automating, and operating cloud platforms — but the role bleeds into **Site Reliability Engineering** (SLOs, error budgets, incident command, blameless postmortems) and **Platform Engineering** (self-service tooling, IaC frameworks, paved-path internal platforms). I care about making on-call boring and deployments forgettable.

## 💼 What I Do
- **DevOps & Cloud (core)**: Build and operate multi-account AWS (EC2, EKS, VPC, RDS, Lambda, IAM) and Kubernetes (EKS, AKS, OpenShift) at production scale. IaC with Terraform and CloudFormation. CI/CD on GitLab CI/CD, Jenkins, AWS CodePipeline, GitHub Actions.
- **Site Reliability Engineering**: Define SLOs/SLIs and error budgets, lead incident response as Incident Commander, run blameless postmortems, build self-healing automation that reduces toil and MTTR. Datadog, Prometheus, Grafana for observability.
- **Platform Engineering**: Design reusable Terraform modules, internal CI/CD frameworks, and paved-path tooling so application teams ship faster without re-solving infrastructure problems.
- **Compliance-first delivery**: Banking-grade pipelines with built-in PCI-DSS, SOC 2, and OSFI controls — security and audit aren't separate stages, they're part of the deploy.

## 🚀 Featured Projects
- **[datadog-sre-demo](https://github.com/VinodKumarDhanavath/datadog-sre-demo)**: End-to-end Datadog observability stack on AWS — 99.5% SLO with multi-window error-budget burn alerts, instrumented APM/logs/traces, and on-call runbooks. Reference for how I think about reliability instrumentation.
- **[self-healing-eks](https://github.com/VinodKumarDhanavath/self-healing-eks)**: Multi-environment EKS provisioned via Terraform, deployed through GitLab CI/CD, with a Lambda-based auto-remediator that resolves ~80% of common pod and node failures without paging on-call.
- **[sre-incident-playbook](https://github.com/VinodKumarDhanavath/sre-incident-playbook)**: Public reference for severity matrix, blameless postmortems, Incident Commander handoff, on-call rotation policy, and capacity planning. The playbook I wish every team had.
